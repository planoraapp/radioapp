# 🌍 Radio Globe - PWA

Uma aplicação web progressiva (PWA) para ouvir rádios de todo o mundo com um globo interativo 3D.

## ✨ Funcionalidades

- **Globo Interativo 3D**: Navegue pelas rádios do mundo arrastando e dando zoom
- **Seleção AM/FM**: Alterne entre bandas de rádio com scroll horizontal
- **Controles de Reprodução**: Play/Pause, favoritos e navegação
- **Interface Mobile-First**: Otimizada para dispositivos móveis
- **Progressive Web App**: Instale como um app nativo
- **Design Minimalista**: Interface preto/branco/vermelho inspirada em apps modernos

## 🚀 Como Usar

### Desenvolvimento
```bash
cd web
npm install
npm start
```
Abre em [http://localhost:3000](http://localhost:3000)

### Build de Produção
```bash
cd web
npm run build
```

## 🛠️ Tecnologias

- **React 19** - Framework principal
- **TypeScript** - Tipagem estática
- **Three.js + React Three Fiber** - Renderização 3D
- **Tailwind CSS** - Estilização
- **Lucide Icons** - Ícones
- **Service Worker** - Funcionalidades offline
- **PWA Manifest** - Instalação como app

## 📱 PWA Features

- ✅ **Instalável**: Adicione à tela inicial
- ✅ **Offline**: Funciona parcialmente sem internet
- ✅ **Responsivo**: Adapta-se a qualquer tamanho de tela
- ✅ **Fast**: Carregamento otimizado
